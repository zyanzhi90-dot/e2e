# Method Design — Candidate Principles

Design cycle: `MDCYCLE-2026-08-29-01`

This packet presents Candidate Principles for Human discussion and selection. It does not contain a test plan, execution set, or cost approval.

## SP-DECISION-SUFFICIENT-QUOTIENT · version 1

**Principle.** Use the coarsest observable equivalence classes preserving conditional action ranking and outcomes.

**Mechanism.** Partition observations by conditional decision equivalence. This changes Scalar alias becomes a consequence-preserving quotient.. Preserves only RCA-relevant spatial distinctions.

**Provisional Scientific Delta.** Minimal spatial state and scalar-sufficient boundary.

**Primary risks.** A stable low-dimensional observable quotient exists across held-out shifts. → Retire or narrow the Principle.

**Substantive difference.** Separates spatially aliased contact configurations by conditional action/outcome equivalence; unlike the wrench-margin Candidate it is not tied to proximity to wrench limits, unlike the predictive-state Candidate it does not require memory, and unlike feedback-gated simplicity it defines the retained state rather than when complexity is worth using.

**Status.** ACTIVE: Falsifiable spatial competitor; no full-field commitment.

## SP-WRENCH-FEASIBILITY-MARGIN · version 1

**Principle.** Use the smallest observable coordinate of remaining direction-dependent wrench feasibility.

**Mechanism.** Map observations to calibrated feasible-set slack. This changes Raw contact variables become a capacity-relative order coordinate.. Directly restores missing pre-limit authority.

**Provisional Scientific Delta.** Minimal pre-limit coordinate and normal-only boundary.

**Primary risks.** True feasibility slack mediates added information's action value. → Reject margin sufficiency.

**Substantive difference.** Orders states by remaining direction-dependent wrench slack; unlike the decision-sufficient quotient it commits to a capacity-relative causal coordinate, unlike predictive contact state it is instantaneous rather than historical, and unlike feedback-gated simplicity it targets pre-limit feasibility rather than the global complexity gate.

**Status.** ACTIVE: Stricter physics-relative competitor; killable by failed mediation.

## SP-PREDICTIVE-CONTACT-STATE · version 1

**Principle.** Use the lowest-order observable controlled-future predictions that render history conditionally irrelevant.

**Mechanism.** Compress safe action-observation history into finite future predictions. This changes Raw history becomes finite observable predictive state.. Restores temporal sufficiency without constitutive identification.

**Provisional Scientific Delta.** Falsifiable predictive-state order boundary.

**Primary risks.** Finite stable predictive state exists at safe excitation and online latency. → Reject/narrow; do not substitute detailed latent state.

**Substantive difference.** Represents irreducible history through controlled-future predictions; unlike the spatial quotient or wrench margin it requires finite temporal state, and unlike feedback-gated simplicity it specifies how to encode memory rather than when any enriched state has closed-loop value.

**Status.** ACTIVE: Predicts irreducible finite memory; exposed to zero-order killer.

## SP-FEEDBACK-GATED-SIMPLICITY · version 1

**Principle.** Default to the simplest state; enrich only where unabsorbed mismatch changes actions and independent outcomes.

**Mechanism.** Gate complexity on prospective closed-loop decision value. This changes Rich state becomes a regime-conditioned option with simple fallback.. Makes feedback absorption a positive null result.

**Provisional Scientific Delta.** Closed-loop relevance map allowing a richer-is-unnecessary conclusion.

**Primary risks.** A measurable boundary separates absorbed from decision-relevant mismatch. → Reject gating; report a global winner or heterogeneity.

**Substantive difference.** Acts as the simple/null meta-principle that permits any richer Candidate only where mismatch survives feedback and changes independent outcomes; unlike the other three it can conclude that no enriched representation is needed in an absorbed regime.

**Status.** ACTIVE: Required simple/null competitor; prediction gain cannot defeat it.
