# Method Design — Candidate Principles

Design cycle: `MDCYCLE-SOFTSCAN-V2-R9-COMPLETE-DASCO-TOTAL-ACTION`

This packet presents Candidate Principles for Human discussion and selection. It does not contain a test plan, execution set, or cost approval.

**Solution-space constraint.** CONSTRAINED: The accepted contact-state-aliasing RMC requires a history/action-conditioned decision-sufficient contact operator with an explicit calibration-out update, while the accepted selection-feasibility RMC requires one relation from the same context, physical margins and computation state to the action actually rendered. No evidence supports adding a second active Principle after this reduction.

## P-ADAPTIVE-CONTACT-FEASIBLE-INCUMBENT · version 1

**Principle.** Represent continuous soft contact by a recursively adapted, decision-sufficient action-conditional operator. At every update, classify the pre-outcome context-action pair as supported, unsupported-but-inside the adaptation envelope, or outside that envelope but inside the declared withdrawal envelope. Supported scan actions use calibrated margins; adapting scan actions must belong to an independently valid envelope-feasible set and posterior belief may only further restrict them or shape their objective; outside-envelope states return a preverified withdrawal impedance/reference action in constant time. The remaining scan-mode decision is rendered by incumbent persistence or viability. In SUPPORTED or ADAPTING scan mode, totality is realized by verified-incumbent persistence; OUTSIDE-ENVELOPE returns u_wd directly.

**Mechanism.** Construct and adapt the support-aware predictive contact operator. In SUPPORTED scan mode verify RTI-SQP candidates in F_cal; in ADAPTING scan mode verify them in F_adapt, which is always a subset of F_env. Atomically replace the shifted incumbent only after verification, otherwise return it. OUTSIDE-ENVELOPE bypasses the optimizer and returns the preverified withdrawal tuple u_wd before the same deadline. This changes NNBO fixed scalar preidentified contact law -> history- and action-conditioned predictive contact operator with explicit support state -> active in-envelope adaptation under a valid envelope relation -> posterior-aware constrained normal-tangential impedance selection -> one of two explicit totality mechanisms.. The contact operator preserves exactly the history information that changes feasible impedance or its ranking. During calibration-out adaptation, F_adapt is constructed so F_adapt is a subset of F_env by definition; posterior belief can veto actions or shape objective/information value but cannot relax F_env before audited re-entry. Leaving the adaptation envelope activates a controller-internal withdrawal branch with a preverified dissipative gain/reference action and constant-time lookup. Thus all three support states produce an applied action while arbitrary-shift performance or safety is not claimed. The scan-mode totality mechanism remains open between incumbent persistence and viability certification.

**Provisional Scientific Delta.** A support-state-aware adaptive decision-sufficient contact operator that converts calibration-out soft-contact changes into constrained impedance decision recovery rather than detection or refusal, paired with one of two still-competing totality mechanisms. Variant A adds interruption-safe verified-incumbent persistence without making the optimizer itself the paper headline.

## P-DECISION-SUFFICIENT-ADAPTIVE-CONTACT-TOTAL-ACTION · version 1

**Principle.** Represent continuous soft contact by a compact action-conditional predictive state whose equivalence is defined by robust feasible impedance and decision value. Use episode-calibrated simultaneous margins only for supported context-action pairs; after in-envelope support loss, update a bounded low-dimensional residual set from contact data and choose performance or information-bearing impedance only when it satisfies the set-robust hard relation. Define the applied action as one hybrid scan/withdraw tuple and include a preverified withdrawal tuple in the same relation at every declared update, so optimization improves scan performance while infeasibility, model inconsistency or deadline returns an on-time feasible action without an external guard.

**Mechanism.** Use a frozen causal latent operator with a low-dimensional affine residual head to predict H-step force, trajectory, contact/slip, finite-area wrench, energy and actuator outcomes under candidate four-gain impedance sequences. Train the latent state against multistep likelihood, feasible-set disagreement and constrained decision regret. On supported pairs impose an episode-calibrated simultaneous tube; on support loss perform bounded-drift set-membership/RLS residual adaptation and impose worst-case set margins. Solve normal-tangential impedance by warm-start RTI-SQP with explicit gain, wrench/contact, energy and actuator constraints while maintaining only fully checked scan iterates. Enumerate a preverified withdrawal tuple in the same hybrid action relation and publish the best valid scan tuple or withdrawal before the deadline. This changes Trial-fixed scalar or generic point contact prediction -> history/action-conditioned decision-sufficient joint outcome operator -> support-specific calibrated or adaptive-set margin authority -> constrained normal-tangential impedance and information decision -> one hybrid scan/withdraw applied-action relation.. The first structural change separates histories exactly when they move feasible impedance or its ranking, and the bounded residual set lets calibration-out but representable contact changes update the relation rather than merely trigger refusal. The second structural change makes performance, all hard physical margins, energy, computation completion and withdrawal arguments of the same action map. A preverified withdrawal member supplies totality, so neither unverified optimizer output nor an external post-hoc action can become the realized control.

**Provisional Scientific Delta.** A single complete method that learns only contact information needed by constrained impedance decisions, actively repairs representable calibration-out changes under an explicit robust authority, and makes normal-tangential performance, physical limits, energy, computation and withdrawal one applied-action relation. The delta is prospective until discriminating evidence rejects the calibrated-memoryless and post-hoc-guard rivals.
