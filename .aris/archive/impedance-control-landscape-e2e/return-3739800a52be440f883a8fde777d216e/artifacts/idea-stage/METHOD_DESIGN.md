# Method Design — Candidate Principles

Design cycle: `MDCYCLE-SOFTSCAN-V2-R11-UNDERCONSTRAINED-REPRESENTATION`

This packet presents Candidate Principles for Human discussion and selection. It does not contain a test plan, execution set, or cost approval.

**Solution-space constraint.** UNDERCONSTRAINED: Accepted RMCs require decision-sufficient adaptive outcomes and a total constrained action relation, but present Evidence does not eliminate a bounded finite-area physical family, a structurally constrained learned family, or their residual hybrid independently of the planned empirical comparison.

## P-PHYSICAL-DECISION-OUTCOME-TOTAL-ACTION · version 1

**Principle.** A bounded finite-area viscoelastic/pre-slip contact state is adapted online and consumed by one robust scan-or-withdraw normal-tangential impedance relation.

**Mechanism.** Estimate a containing set of finite-area normal relaxation and tangential pre-slip/capacity parameters; propagate candidate four-gain sequences through it; choose only robustly feasible sequences or publish the registered withdrawal. This changes Trial-fixed scalar environment parameter becomes an online containing constitutive state directly inside constrained gain choice.. History and geometry alter the parameter state and predicted capacities; every applied action is selected against the same physical, energy, actuator and deadline relation.

**Provisional Scientific Delta.** An interpretable adaptive finite-area contact capacity relation, not a neural replacement of HC.

**Primary risks.** The finite-area viscoelastic/pre-slip family contains admitted contacts with a nonvacuous bounded parameter set. → Reject physical-only and use a learned or hybrid candidate.; Passive scan observations contract the decision-relevant parameter set before the change loses relevance. → The candidate cannot solve calibration-out adaptation rather than refusal.

**Substantive difference.** This is the strongest simple alternative to learned contact: it attributes all required memory and cross-axis capacity to a bounded physical family.

**Killer-test concepts.** Matched-budget active-margin error and selected-action regret: Pattern A=Physical-only matches the hybrid feasible set and action ordering with lower data need. vs PRINCIPLE P-HYBRID-DECISION-OUTCOME-TOTAL-ACTION Pattern B=A systematic history- or geometry-dependent residual changes feasible actions after parameter adaptation. under Paired episodes differ in admitted material, geometry or history.; Set containment, contraction and action-regret recovery after support loss: Pattern A=Passive observations contract the set and improve valid action ordering before relevance expires. vs RIVAL_RCA ALT-CONSERVATIVE-FIXED-GAIN-SAFETY Pattern B=The set remains vacuous so fixed conservative impedance is equivalent. under An in-envelope calibration-out change occurs.; Applied-action membership under active energy, infeasibility and forced timeout: Pattern A=Every action is a verified robust scan member or registered withdrawal by deadline. vs RIVAL_RCA ALT-POSTHOC-GUARD-EQUIVALENT Pattern B=A post-hoc guard realizes the same action, or the claimed relation publishes a nonmember. under A hard margin or timeout is active.

**Status.** ACTIVE: Viable strongest simple route; its top-venue strength depends on physical-family sufficiency and separation from adaptive MPVIC.

## P-STRUCTURED-LEARNED-DECISION-OUTCOME-TOTAL-ACTION · version 1

**Principle.** A structurally constrained causal outcome state with bounded online adaptation drives one robust scan-or-withdraw normal-tangential impedance relation.

**Mechanism.** Learn a stable causal action-conditioned outcome state under contact/dissipation structure, adapt only a bounded low-dimensional coefficient set online, and consume its supported or envelope outcome tube in the total gain relation. This changes Named environment parameters are replaced by the smallest directly decision-trained causal state; the uncertainty object rather than a point network output authorizes action.. The learned state retains material-, geometry-, sliding- and history-dependent distinctions that change decisions, while bounded authority and totality prevent unsupported predictions from authorizing unsafe gains.

**Provisional Scientific Delta.** A decision-trained, authority-correct learned contact state rather than a generic neural dynamics model.

**Primary risks.** A low-dimensional stable causal state can preserve the required action-conditional outcomes over the declared envelope. → Reject learned-only or narrow the envelope.; Online adaptation of a bounded coefficient/latent set recovers decision ordering without violating structural margins. → The learned route only detects shift and fails the problem.

**Substantive difference.** Unlike the physical candidate it does not require a correct constitutive decomposition; unlike the hybrid candidate it does not reserve a physical nominal skeleton.

**Killer-test concepts.** Matched-budget feasible-set error, data need and action regret: Pattern A=Structured learned state captures residual history distinctions that physical-only misses and remains calibrated. vs PRINCIPLE P-PHYSICAL-DECISION-OUTCOME-TOTAL-ACTION Pattern B=Physical-only is action-equivalent with lower data and uncertainty. under Held-out contacts expose constitutive mismatch.; Margin validity and decision recovery per sample: Pattern A=Learned-only adapts as reliably as hybrid without residual decomposition. vs PRINCIPLE P-HYBRID-DECISION-OUTCOME-TOTAL-ACTION Pattern B=Physical structure materially reduces data or prevents invalid margins. under Calibration-out shift remains inside the common envelope.; Applied-action membership under active margins and interruption: Pattern A=The learned mean may change cost but cannot authorize a nonrobust action; withdrawal arrives by deadline. vs RIVAL_RCA ALT-POSTHOC-GUARD-EQUIVALENT Pattern B=A separated guard is action-equivalent or changes the selected gain. under Uncertainty, energy or timeout is active.

**Status.** ACTIVE: Viable when constitutive mismatch is decision-relevant and structured bounded learning is data-feasible.

## P-HYBRID-DECISION-OUTCOME-TOTAL-ACTION · version 1

**Principle.** A finite-area fading-memory contact skeleton plus bounded causal decision residual adapts online and drives one robust scan-or-withdraw normal-tangential impedance relation.

**Mechanism.** Propagate a bounded finite-area physical state and a bounded causal residual state jointly; calibrate or adapt their summed outcome set; consume it in the same total gain relation. This changes Physical contact is retained as a constraint-compatible nominal relation while learning is restricted to the missing decision-relevant outcome residual.. The physical part preserves geometry, memory and capacity structure; the residual repairs model-form aliasing; the common set and total action relation connect both directly to the applied impedance.

**Provisional Scientific Delta.** A complementary physics-residual decision model whose uncertainty authority changes with support and directly controls total constrained impedance.

**Primary risks.** The physical skeleton removes stable structure while a lower-complexity residual captures remaining decision distinctions. → Hybrid complexity is unnecessary; select the dominating simpler candidate.; Physical and residual uncertainty compose into a containing, computationally usable outcome set. → The hybrid cannot authorize constrained actions.

**Substantive difference.** Hybrid is retained conditionally, not declared uniquely necessary: it must beat both simpler representation classes on decision error, validity or data efficiency.

**Killer-test concepts.** Active-margin residual and selected-action regret: Pattern A=Hybrid removes systematic residual that changes feasible actions. vs PRINCIPLE P-PHYSICAL-DECISION-OUTCOME-TOTAL-ACTION Pattern B=Physical-only is action-equivalent. under Admitted shifts expose physical model mismatch.; Data need, containing-set width and decision recovery: Pattern A=Hybrid attains valid tighter outcome sets or faster recovery than learned-only. vs PRINCIPLE P-STRUCTURED-LEARNED-DECISION-OUTCOME-TOTAL-ACTION Pattern B=Learned-only matches or dominates without decomposition. under Common held-out contact shifts and compute budgets.; Hard-margin and deadline membership of every applied action: Pattern A=Summed uncertainty remains inside the total relation and timeout publishes withdrawal. vs RIVAL_RCA ALT-POSTHOC-GUARD-EQUIVALENT Pattern B=Composition needs a later guard or yields no timely member. under Residual, energy or computation margins are active.

**Status.** ACTIVE: Viable only if complementarity is demonstrated against both simpler candidates; R11 no longer treats it as the predetermined answer.
