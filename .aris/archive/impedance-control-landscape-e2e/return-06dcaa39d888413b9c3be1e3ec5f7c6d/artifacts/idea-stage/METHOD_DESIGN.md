## P-ADAPTIVE-CONTACT-FEASIBLE-INCUMBENT · version 1

**Principle.** Represent continuous soft contact by a recursively adapted, decision-sufficient action-conditional operator. At every update, classify the pre-outcome context-action pair as supported, unsupported-but-inside the adaptation envelope, or outside that envelope but inside the declared withdrawal envelope. Supported scan actions use calibrated margins; adapting scan actions must belong to an independently valid envelope-feasible set and posterior belief may only further restrict them or shape their objective; outside-envelope states return a preverified withdrawal impedance/reference action in constant time. The remaining scan-mode decision is rendered by incumbent persistence or viability. In SUPPORTED or ADAPTING scan mode, totality is realized by verified-incumbent persistence; OUTSIDE-ENVELOPE returns u_wd directly.

**Mechanism.** Construct and adapt the support-aware predictive contact operator. In SUPPORTED scan mode verify RTI-SQP candidates in F_cal; in ADAPTING scan mode verify them in F_adapt, which is always a subset of F_env. Atomically replace the shifted incumbent only after verification, otherwise return it. OUTSIDE-ENVELOPE bypasses the optimizer and returns the preverified withdrawal tuple u_wd before the same deadline. This changes NNBO fixed scalar preidentified contact law -> history- and action-conditioned predictive contact operator with explicit support state -> active in-envelope adaptation under a valid envelope relation -> posterior-aware constrained normal-tangential impedance selection -> one of two explicit totality mechanisms.. The contact operator preserves exactly the history information that changes feasible impedance or its ranking. During calibration-out adaptation, F_adapt is constructed so F_adapt is a subset of F_env by definition; posterior belief can veto actions or shape objective/information value but cannot relax F_env before audited re-entry. Leaving the adaptation envelope activates a controller-internal withdrawal branch with a preverified dissipative gain/reference action and constant-time lookup. Thus all three support states produce an applied action while arbitrary-shift performance or safety is not claimed. The scan-mode totality mechanism remains open between incumbent persistence and viability certification.

**Provisional Scientific Delta.** A support-state-aware adaptive decision-sufficient contact operator that converts calibration-out soft-contact changes into constrained impedance decision recovery rather than detection or refusal, paired with one of two still-competing totality mechanisms. Variant A adds interruption-safe verified-incumbent persistence without making the optimizer itself the paper headline.

## P-DECISION-SUFFICIENT-ADAPTIVE-CONTACT-TOTAL-ACTION · version 2

**Principle.** Represent continuous soft contact by the smallest structured hybrid predictive state that preserves normal-tangential impedance feasibility and ordering: known finite-area, fading-memory and capacity structure is explicit, while only decision-relevant unmodeled effects occupy a bounded residual set. Use a calibrated simultaneous outcome set on supported episodes and, after in-envelope support loss, update the residual set by drift propagation, innovation-triggered reset and action-outcome consistency without allowing the estimate to relax the declared envelope margins. Select coupled normal-tangential impedance through one short-horizon robust total-action relation that internalizes contact, wrench, energy, actuator, gain-rate and deadline constraints and always contains a preverified withdrawal action.

**Mechanism.** Build a low-order structured hybrid contact operator in the moving contact frame. Its physical state carries indentation/patch geometry, stable viscoelastic memory and tangential pre-slip/capacity; a bounded action-conditioned residual corrects only the H-step joint outcome and active-margin errors left by that skeleton. On supported episodes use an independently calibrated simultaneous one-sided outcome set. After support loss, propagate the residual parameter set by the admitted drift bound; when an innovation falsifies that continuation, reset once to the declared envelope set and intersect with new consistency strips. The current set center may shape nominal cost, but every adapting scan action must satisfy the independently valid envelope relation for all residuals. Optimize four positive normal/tangential stiffness-damping gains over a horizon covering the dominant contact memory, with wrench/contact/slip, energy-tank, actuator and gain-rate constraints. Permit decision-disambiguating excitation only lexicographically among robustly feasible near-optimal actions. Publish only a fully verified scan action; otherwise publish the preverified rate-limited unload-and-stop withdrawal action before the deadline. This changes Calibration-fixed point law or unconstrained black-box transition -> structured physical contact memory plus bounded decision residual -> support-indexed calibrated or envelope-robust outcome set -> short-horizon four-gain impedance decision with integrated energy and hard margins -> one scan/withdraw applied-action relation.. Explicit memory and capacity coordinates separate the histories and patches diagnosed by the first chain, while the residual set adapts representable calibration-out changes instead of merely detecting or rejecting them. The second chain is repaired because the same action variable is evaluated for task cost, contact capacity, energy, actuator reachability, gain rate, verification completion and fallback. No downstream projection can silently replace the optimized action.

**Provisional Scientific Delta.** A structured hybrid, decision-sufficient contact operator that changes uncertainty authority when calibration support is lost and drives one multistep normal-tangential total-action impedance relation. The scientific claim is the coupled representation-adaptation-decision relation, not a new recurrent network, estimator, solver or energy tank.

**Primary risks.** The explicit contact skeleton plus bounded residual preserves every distinction that changes the robust feasible set or action value over the declared four-gain class. → Expand or replace the representation; if the simpler physical or memoryless class is equivalent, reject the hybrid mechanism.; Every admitted calibration-out change lies in the declared physical/residual envelope after either bounded drift propagation or one change-triggered reset. → The adaptive relation cannot authorize scanning; narrow the claim envelope or redesign the representation.; Independent supported calibration episodes satisfy the declared episode-level dependence or exchangeability conditions for simultaneous one-sided margins. → Do not invoke supported authority; use the envelope-robust relation or withdraw.; The chosen horizon covers the shortest interval in which relaxation, slip/contact loss, gain-rate or energy effects can change the current impedance decision. → The predictive decision may be myopic; increase the horizon or, if one step is equivalent, demote multistep MPC.; Set propagation, support functions and bounded nonlinear remainders conservatively represent every declared hard margin within the update budget. → A verified scan action may not belong to the claimed relation.; The interaction-energy state accounts for gain variation, reference work, delay and bounded unmodeled port work. → The energy constraint and its passivity interpretation fail.; Every admitted operating state lies in an envelope where stopping tangential motion and rate-limited normal unloading is feasible and monotonically releases contact. → The total relation is not total; narrow the envelope or add a lower-level certified emergency relation.; Measurement, set update, withdrawal lookup, verification and atomic publication have measured worst-case time below the reserved update deadline. → Solver-independent deadline totality fails.
